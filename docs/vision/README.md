## 📝 Mantenimiento

### Actualización de Versiones
Si se actualiza una dependencia, **solo modifica** [stack.md](./stack.md) - es la fuente única de verdad.

### Cambios de Alcance
Si cambia el scope del MVP, actualiza [alcance.md](./alcance.md) y documenta la razón del cambio.

### Nuevos Objetivos
Si surgen nuevos objetivos, agrégalos a [objetivos.md](./objetivos.md) con fecha de incorporación.
